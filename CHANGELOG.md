# Changelog

## [0.2.0] — 2026-10-29 (prepared locally)
- Added SQLite WAL run/event persistence, restart marking for interrupted runs, run listing and cancellation.
- Added authenticated browser screenshot endpoint.
- Added persisted website-monitor subscriptions and optional best-effort single-process scheduler (off by default).
- Expanded Python SDK and dashboard controls for recent runs and cancellation.
- Added proprietary copyright license, security threat model, evaluation protocol, animated architecture/hero and generated local-product demo media.
- Added new persistence, API and browser tests; no claim of complete remote-browser SaaS or full competitor parity.
- This build is a **local release candidate**; not automatically pushed to GitHub or deployed.

## [0.1.0] — 2026-10-28
- Branded independent browser-agent MVP with API, browser sessions, extraction, manual monitor and optional MCP adapter.
- Established modular product boundaries (Agent, Browser, API, Core), docs, tests and local Docker Compose foundation.
